# JSTP 理论对照审阅：从“会看后果”到“会预测自己接下来怎么做”

2026-11-18 · 对照[详细理论稿](JSTP-详细理论稿.md)、[已封存论文](../paper/manuscript.md)、实际执行代码和[原始统计](../evidence/paper/analysis/metrics.csv)。本文是审阅与下一轮方案，不是新增实验结果；不改动已封存的论文、代码与证据。

## 一、五项主张，不是五项已经得到的结论

| 主张 | 我对它的理解 | 什么能检验它 |
|---|---|---|
| 世界事物的本质是联合转移 | 作者的世界观比原稿 §2.1 的最低假设强。可以保留本体论立场；实验只需假定局部可区分、可共同变化，系统只能观察其中一部分。联合不等于所有部分一起动，转移也不自动等于因果。 | 任一模拟器都可以写成状态转移，因此模拟器可运行不是本体论证据。可以测的是：过去的联合变化是否有助于预测下一次干预的局部后果。 |
| 预测是基本功能，结构使分割成为可能 | 神经元或人工网络的活动可以分别变化，这是**载体可分**；哪些区域要一起预测、哪些在松手后应分开，是**经验形成的功能性分组**。不需要先安装识别杯子、手或边缘的独立模块。 | 没有对象标签，分别改变外观、挂接与运动历史。如果只是记住固定空间带，交换位置后就会暴露。一起动过不等于始终是一个个体，还要测脱离、重现或独立干预。 |
| 高级智能只存在于语言层 | 按作者的强说法，高级活动不是预测之外的新运算，而是预测开始以可组合的语言内容作条件、预测对象和下一轮输入。“按开关会避开危险”和“判断某项因果主张是真是假，并在反例下修正”不是一个指标。 | 先给“高级”一个不依赖会不会说话的任务定义，再比语言回输与等资源非语言回输。若把“高级”直接定义成“能说”，则“高级只在语言层”变成定义，不再是实验发现。严重失语者在部分非语言因果题上仍能作答，是对广义排他主张的约束；单病例也不能抹掉其既往语言经验。[Varley 与 Siegal 的实验](https://pubmed.ncbi.nlm.nih.gov/10873809/) |
| 行动是预测的自身部分得到落实，不必另有判断者 | 当前视觉、身体状态、习惯、任务或冲动一起影响后继状态。在“我要伸手”的情境中，自身运动通道可以落实预测；在“看别人伸手”“想象伸手”或“手被别人抬起”的情境中，相似的视觉预期不等于自己发出相同运动命令。预测不必长成清晰图像。 | 先封存预期的自身运动和外界改变，再执行。固定现实、目标和此前动作，只干预模型内部预期，检验自身输出是否按物理上可解释的方向改变，而不靠外部程序替它选。 |
| 自我、心声与回输 | 区分“没有额外的内在指挥者”“没有主观体验”“内部产物再输入可延长处理”“必须经过外周感受器”四个命题。原稿 §11.2–11.3 明确保留这种区分；本轮的字面强说法应记录为假说，而不以较弱实验偷换。 | 人工模型可测回输内容是否支持更长的任务依赖；不能裁定人有没有体验，也不能凭模型定位人脑的生理回路。内言研究发现：默念的音节与同时听到的音节一致时，听觉诱发反应减弱。这显示两者相互影响，不证明心声必须从耳朵绕一圈。[Whitford 等，原始实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC5714499/) |

这里统一的是**持续预测这一运行原则**，不是要求网络内没有功能分化，也不是规定每一次行为都先生成一部电影。数学上，直接策略输出也可以叫作动作预测；光改名称没有实质内容。值得押注的强版本是：在某些必须利用经验的场景，**对世界将怎样变化的那部分预期，确实参与了自身行动的形成**。

## 二、现有论文回答了前半题

- [arena.py](../jstp/arena.py) 的 `scene` 由环境提供两个抓取点及正式拖动位移。[v7_model.py](../jstp/v7_model.py) 的 `JointFuture.forward` 接收候选运动，用它的位移平移网络预测的三通道信号。网络预测的是**在已给运动下**载荷和可见把手会怎样；把手出现在未来像素中，不代表运动命令是网络自己预测的。
- [learn.py](../jstp/learn.py) 的 `costs` 按目标区域算像素误差；`branch_loss` 除实测分支重建外还使用成对差与目标排序。[exam.py](../jstp/exam.py) 的 `forecasts` 对候选代价取最小，`score` 才实际执行。因此这版不是“直接动作头换个名字”，预测确实进了执行链；也不是“无外置选择器、自发生成自身运动”。外置比较器是实验装置，不是一个有意识的主体。
- 熟悉连接、新双区目标：JSTP **88.7%**，同结构仅分别重建各分支 **49.7%**，完整历史直接策略 **89.1%**。相同把手与局部在两种连接下都判对跟动与否，JSTP **51.7%**，留出新连接仅 **16.0%**。这是可见局部共动的行为证据，不是网络已发现稳定个体，也不是对全部智能源于预测的证明。
- “同动作换目标，后果不变”在旧版由目标不进入转移网络保证。它是有用的设计校验，不是独立学出来的认知能力。主试验没有语言交互或内言回输；读取三帧真实历史也不等于把自己刚产生的预测再次送入同一网络。

## 三、下一版优先只做一个问题：不用外置裁判，行动能不能从联合预期中产生？

**场地不换，先换研究问题。** 保留独立窗口、熟悉挂接、冻结测验和真实执行。第一轮不增加遮挡难度、不追排名，也不同时上语言。实现上用同一套权重更新一份共同状态：当前观测、历史自身命令、身体反馈和行动前就已存在的目标线索进入网络；下一拍自己的驱动量与外界、身体的变化共同作为待补全内容。部署时不喂入备选 A/B 指令，不用目标误差挑未来，不另建动作策略、价值网或分割器。无动作也应是合法输出。执行器只翻译自身驱动通道，动作结果由虚拟世界返回；供人看的预测图是测量窗口，不是智能的必经步骤。

**数据必须跟着改。** 现有同一历史遍历 A/B 的数据很适合学“如果我被要求做 A 会怎样”；把两条运动都当作同一目标下“我正要做”的正样本，却不给行为来源，不能教出自主倾向。旧分支仍可学物理。新增轨迹要按时间记录“事前的目标与经历 → 实际发出的驱动或保持不动 → 身体与世界实测 → 后续纠正”。既有不同目标下的真实行动示范，也有失败、改正和外力导致身体移动但自己没有发令的例子。示范是一种经验来源，应披露；不得把未来成败、正确把手或真实接线塞入行动前输入。训练监督来自实际记录的自身及外界后续，不从比较器倒算一份最优动作标签。

**最小对照。** 同一数据、容量和内部更新次数下，比较联合预测回输、完整历史直接策略、同时训练动作与后果但后果不回输的网络；旧的外置比较器单列作参照。可以把回输安排成相同权重的两次更新，以便在中间做干预；这是为测量而选的结构，不是宣称大脑必须先看画面再动。

为什么只看两个输出不够？按概率链式法则，动作与后果的联合分布也能写成“给定历史和目标的动作分布”乘以“已给这个动作之后的后果分布”。先决定手怎么动、再补画一张后果图，完全可能给出一样的外在记录。要区分它与“联合预期参与形成运动”，必须在**动作尚未提交**时动到那段计算，不能只看两项预测的相关性。

| 冻结权重后怎么改题 | 应提前封存并核对什么 |
|---|---|
| 末帧、目标不变，换真实试探经历 | 自身运动是否随相关接线而变，局部预期是否跟着变，实际执行是否兑现；分别记分，不只记通关。 |
| 经历不变，只换目标 | 自主状态下，自身运动及其导致的世界未来**可以变**；在单独的测量试次中由实验者钳住相同运动，若目标不改变物理，则该运动的预测后果**不应随愿望改写**。钳住只用于验收，不给正常控制送答案。 |
| 手的可见轨迹相同，改变运动来源 | 一种情境需要自己驱动，另一种有可预知的外力使手沿相同轨迹移动，且无需主动补偿；过去的本体感觉或任务线索应使二者可辨。在两种情境下应都能预见手移动，却不应都预测自己发出驱动。 |
| 现实、目标、内部初始驱动均不变，只换一次回输 | 在可控的内部更新间，替换**与挂接有关的、将回到网络的局部感觉预期**，不替换整份隐状态或运动通道；供体来自相配的孪生场景。同时做相同接线的假交换和无关区域替换，检查不是任意扰动都会使动作翻转。应在预测的方向上改变运动；真实接线并未改变，错误预期可能使执行失败。 |

可判定的失败：模型会通关，但去掉相关后果回输与假交换没有可区分的影响，或只改输出显示图才声称干预了动作——前者没有给出该回路参与控制的证据，后者根本没测到回路。模型按预期翻转但真实后果常错，则测到了依赖，没有测到理解正确。先公布方向、配对指标与区间口径；与直接策略同分并不妨碍得到机制证据。这些判据针对该实现，不把一个实现失败升级成对整套理论的否证。

## 四、论文和后续研究怎样改

1. **保留现论文及其负结果。** 投稿修订时，在引言把“给定自身动作，预测世界后果”和“自身动作也是待预测量”并列。建议把副标题中的“功能性分组的形成”改成“从试探经验预测局部共动及其迁移边界”，或保留原题而在摘要第一段给出操作定义。正文方法已说明候选与比较器；应在摘要、结论也保留这个边界。
2. **可直接用于摘要或讨论的表述：**“在不提供对象标签、但提供候选运动、平移先验与目标比较规则的条件下，网络利用试探经历改善了对熟悉机构中局部共动的预测及其在新目标选择中的应用。本文没有检验运动命令能否由同一预测过程内生形成，也没有把可见局部共动等同于对象身份。”
3. **语言另做实验证据，不作本篇结论。** 让系统在没有新外界线索时，处理几步可重排的条件、反例与修正，最后用同一种非语言操作答题。比较“自己的可组合符号回输”“同容量、同步数的非语言隐状态回输”“符号内容被等长打乱”。事先定义怎样才算语言，不把任何成功的隐编码事后改叫语言。测的是正确完成几层依赖、能不能迁移到新组合，不是运行得久不久。非语言组也能稳定完成，就反对“这种任务必须使用所定义的语言通道”；符号组领先，至多说明语言在这些条件下有用，不能证明人类所有高级智能只存在于语言。
4. **把“心声延长思维”与“自我意识不存在”分开写。** 前者可转成有实验反例的功能假说；后者保留为作者的哲学立场。删去人工网络中的“我”标签，或者做出能回输的机器，都不能充当人类第一人称体验存在或不存在的实验证明。

最值得争取的下一项结果不是“从 88.7% 刷到 95%”，而是：**没有外部程序替它比较对错时，只改变它对于世界会怎样的内部预期，它对自己下一步运动的预测就发生有方向的改变，并能由实际操作核对。**
