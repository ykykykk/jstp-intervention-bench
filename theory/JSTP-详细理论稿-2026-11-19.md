# 联合状态转移预测智能理论

## 从现实中的共同发生，到语言的自行运行与高级认知

**思想提出：岳轲**  
**文档性质：详细理论稿与形式化草案**  
**初稿整理：2026 年 11 月 16 日；本次修订：2026 年 11 月 19 日**

> **核心命题：智能的基本功能是预测。系统自己就在世界里，它从自身与外界共同构成的情境出发，预测接下来会有什么变化。预测可以只有“我的手会伸出去”，也可以细到手和物体怎样一起移动。“联合”说的是自己和外界本就在同一个变化过程中，不是要求每次都把两者的未来预测齐全。本理论进一步主张：分割可以在同一网络中学成；高级智能只存在于语言层，是这同一预测过程以语言为内容继续运行的结果。**

---

## 摘要

本文提出一种以“联合状态转移预测”为核心机制的智能理论，尝试用同一条解释路线连接现实经验、神经系统、学习、语言、行动、逻辑、因果和科学。

作者的出发点是：世界事物的本质在于彼此联合并不断转移。研究智能所需的前提则更小：观察者能分辨某些局部，也能经历它们一起或分别变化。系统本身也是其中一部分。许多可以分别活动、又相互连接的单元，为它区分局部提供了条件；哪些局部会被当作同一物体来追踪，则取决于连接、当下活动与过往经验。无须先给网络一份分好的对象清单。

观测可以不完整，预测本身也可以不完整。看见杯子滑落，系统可以直接预测自己伸手，也可以只预期杯子大致向下，并不需要在后台算出一段没有显示的视频。反过来，若接住杯子需要更细的时机和位置，理论也允许预测这些细节。学习留下的不只是哪次发生了什么，还有以后怎样分辨、追踪和预测；压缩不必另设为一种基本智能机制。

语言不是一个已经理解世界的主体主动设计出来的编码工具。声音、动作、表情和文字，起初都只是现实状态中的元素。在共同活动中，这些元素与其他状态反复一起出现，使人能够从部分状态预测其余状态及后续变化。一个词不是整件事情的总括，也不是对完整现实的替换；它是能够引出后续预测的一个状态元素。当声音和符号越来越多地与其他声音和符号发生预测联系，语言便形成了可以暂时脱离当前外部场景而继续运行的状态空间。

本理论的强主张是：非语言预测可以很复杂，也可以把事情做对，但它本身不作“这个理由成立吗”“这件事是对是错”一类判断；这样的高级智能只在语言层形成。作判断时，底层仍是同一网络在预测，并没有多出一个裁判。行动则不必经过这一步：对自身下一动作的预测可以经身体或执行接口直接实现。详细预想后果、比较再行动，是这个框架容许的另一种做法，不是行动的定义。

由此，理论指向一种统一的人工智能构想：世界、语言、记忆、身体与行动在共同的隐式状态体系中相互预测。不同数据形式提供不同的学习内容，但不要求它们分别对应本质不同的智能。

**关键词：** 联合状态转移；预测；隐式结构；语言涌现；行动；泛化；局部世界；统一多模态智能。

## 一、理论究竟想解释什么

### 1.1 不是给已有能力重新命名

“智能会预测”是一个很弱的说法。无论一个系统是否依赖显式规则、因果图或规划器，它都可能进行某种预测。

本理论的主张更强：

> 感知、语言、推理和行动，不必分别来自几种互不相同的基本智能机制；它们可以是同一个联合状态转移预测过程在不同状态内容上的表现。

这里的重点不是把一切写成“状态发生了变化”。任何计算过程都可以用状态变化来描述，这本身不能解释智能。理论要回答的是：**一个系统能否仅以预测性学习形成可泛化的内部转移结构，并由此产生通常被分别归类的认知能力？**

### 1.2 区分现实层、运行层与语言层

为了避免把解释语言直接投射进模型内部，需要区分三个层次。

| 层次 | 本理论关注的内容 | 不应混淆的事情 |
| --- | --- | --- |
| 现实经验层 | 观察者接触到的共同状态及其变化 | 耳朵可以听到“因为”这个词；听到它，不等于感官已经判明了因果 |
| 隐式运行层 | 内部状态如何在经验中形成，并支持后续预测 | 不因输出符合逻辑，就直接假定内部另有逻辑规则库 |
| 语言与理论层 | 人如何说出对象、关系、因果、逻辑和科学命题 | 不把语言层的概念自动当作底层运行单位 |

这不是三个彼此隔绝的世界。语言发声、文字显示、读写动作以及脑内语言活动，本身仍然进入现实与内部状态的运行。

三层区分的作用是防止解释上的循环：不能先用“人理解了因果”说明某种行为，再把同一种行为当作内部存在因果机制的证明。

### 1.3 “纯预测”不等于什么都没有

本理论中的“纯”，排除的是额外预设的高级认知原语，不是排除系统的实现条件。

系统仍然需要承载状态的物理结构、保留历史影响的能力、学习过程、感觉输入，以及作用于环境的输出接口。它也可以具有不同的时间尺度、局部回路和信息通路。

因此，不能把“纯预测”误读成：没有记忆、没有训练、没有身体、没有反馈，只有一个孤立的函数。更准确的意思是：**这些条件支持一个持续运行的预测系统，而不必再引入独立的因果主体、逻辑主体或决策主体。**

## 二、最小现实与局部世界

### 2.1 最小现实假设

作者提出的世界观是：**世界事物的本质是联合事物的转移。** 这不只是说“我们可以这样记数据”，而是认为事物本就在与其他事物共同变化的过程中存在。要研究一个系统怎样学会预测，不必先证明这个关于整个世界的主张。实验所需的最低限度是：观察者能区分某些部分，并观察到它们怎样共同或分别变化。

用最简单的记号表示：

```text
S_t → S_(t+1)
```

这里的箭头首先表示转移或先后，不自动表示“已经证明的因果作用”。`t` 只是描述当前过程所采用的顺序或采样标记，不要求所有局部世界共享同一个绝对时钟。

“状态”也是本文的描述单位。采用状态表达，不等于断言现实的终极本体就是一帧一帧的静态快照。

### 2.2 可分与联合不是两套额外实体

例如，一个观察范围可以同时包含两个局部部分 `A` 和 `B`：

```text
(A_t, B_t) → (A_(t+1), B_(t+1))
```

这一写法只表示两部分共同处在一个变化过程中。它不要求先有两个完全独立的状态，再由一个额外机制把它们拼接起来。

它也不要求整体能被各部分的独立描述完全穷尽。部分之间共同出现的配置，同样可以是描述整体时需要保留的内容。

因此，“可分”在这里是**可以区分局部**，不是“每个局部一定相互独立”；“联合”是**共同构成一个状态**，不是“必须先被认知系统明确判断为具有关系”。

### 2.3 局部世界理论提供什么

局部世界理论允许不同局部具有不同的状态内容、组织形式与转移方式，不预先要求一套全局词汇能够完整描述一切。

可以用以下记号概括一个局部描述：

```text
W_i = (S_i, T_i)
```

其中，`S_i` 表示该局部可讨论的状态范围，`T_i` 表示其转移描述。这里不保证 `T_i` 能脱离环境独立决定后续状态。

当局部之间能够发生联系时，可以讨论包含它们的更大状态；不能因此直接推断所有局部都能被无条件拼成一个全知的全局模型。

在本智能理论中，局部世界的作用是提供现实背景：**智能面对的是它能够接触的局部世界，并通过有限联系学习其他局部的变化。** 至于异构局部世界是否构成现实的最终本体，是更强的哲学与物理主张，不由智能预测能力本身证明。

### 2.4 智能自己也在世界之内

智能不是站在现实外面观看现实的东西。它的感知、发声、动作以及内部变化，都参与现实状态转移。

因此，经验中的联合状态不仅包含“外面发生了什么”，也包含“我现在怎样”“我刚才做了什么”“别人对我作出了什么回应”。

这为后面把行动纳入预测提供了起点：**自身不是预测模型之外的例外。**

## 三、什么是联合状态

### 3.1 一个状态可以同时包含许多信息

联合状态不是一个不可分割的整体标签。它可以包含视觉、声音、身体感觉、记忆影响、语言活动和正在发生的动作。

为便于解释，可以写成：

```text
Z_t = (视觉信息, 声音信息, 身体信息, 记忆影响, 语言活动, 行动相关信息, ...)
```

但这只是观察者的功能性分栏，不表示内部真的有六个整齐分开的抽屉。

一个简化的实现记号是：

```text
Z_t = (z_1, z_2, ..., z_n)
```

它表示许多可变化单元共同构成当前状态。多个局部信息能够同时参与预测，不必先被命名为对象，也不必先生成一句“A 与 B 有关系”。

### 3.2 生理可分不等于概念一一对应

作者最初提出的关键直觉是：表现一个状态的不是一个整体单位，而是许多神经元共同活动，所以联合状态在生理上有实现基础。

这一点在理论中的含义是：**系统具有许多同时变化的自由度，能够承载复杂的共同状态。** 它不等于以下主张：

```text
第一个神经元就是杯子。
第二个神经元就是手。
第三个神经元就是“推”。
```

本理论不要求这种一一对应。信息可以通过重叠的活动模式共同参与预测。

因此，说“分割源于神经网络自带的结构”，首先是说网络本来就有让局部活动彼此区别、又彼此影响的条件；不是说只要神经元足够多，杯子就已经从桌上分出来了。

### 3.3 从局部差别到一个可以单独操作的物体

杯身的花纹有边缘，手挡住杯身也有边缘。能检测到这两道边，不等于知道前者在杯子上、后者是手遮住了杯子。分割有两面：把不同事物分开，也把外观不同、甚至暂时隔开的部分归到一起。

拿起杯子时，手、杯把和杯身都一起走；松开手时，手可以单独离开，杯把和杯身却仍一起转。一次共同运动分不清这两种关系。一段既有拿起、又有松开的经历，才给了网络区分它们的机会。本理论设想，同一网络为了预测这些不同的后续，会逐渐学会哪些活动应一起保持、哪些要分别更新。这可以成为稳定、可复用的分组方式，不必先给物体命名，也不必输出一张分割图。

要检验它是否真把握了一个个体，可以让遮挡后的末帧看起来完全一样：一段经历里，露出的两端属于同一刚体；另一段里，它们是曾经一起运动的两个物体。只推动左端，记录网络事前预期右端会不会动，再用实际结果核对。**能圈出当前可见区域，是一层证据；能凭先前经历区分同一动作会带动谁，是另一层；遮挡后还能持续追踪身份，又是更强的一层。** 不能用第一层的成绩代替后两层。

### 3.4 “联合”不是额外的认知步骤

不必把过程写成：

```text
识别 A → 识别 B → 建立 A-B 关系 → 拼装联合状态 → 开始预测
```

理论允许更直接的过程：

```text
多种信息共同进入并改变当前内部状态。
当前内部状态立即参与后续预测。
```

“杯子”“手”“接触”“推”等词，可以是后来对这一过程的语言描述，而不必是预测启动前必须完成的内部操作。

### 3.5 统一记号

后文使用以下记号。它们是描述工具，不是要求模型必须设置的模块。

| 记号 | 含义 |
| --- | --- |
| `S_t` | 被讨论的现实状态，不假设系统能够完整获得 |
| `O_t` | 此刻实际获得的局部观测 |
| `Z_t` | 系统此刻的内部联合状态 |
| `H_t` | 当前可利用的交互历史及其留下的影响 |
| `L_t` | 语言相关状态，是整体状态中的一个方面 |
| `A_t` | 行动或控制输出，是自身参与现实变化的一个方面 |
| `θ` | 训练或经验留下的相对持久的参数结构 |
| `Δ` | 预测跨越的步数、事件间隔或时间跨度 |

`O_t`、`L_t` 和 `A_t` 可以在描述上有交叉。例如，听到自己的话既属于声音观测，也属于语言活动。这里不要求它们是互不重叠的物理集合。

## 四、预测如何在不完整信息中持续运行

### 4.1 不需要先接收完整状态

本理论不认为人必须先收集齐所有信息，再对一个完整世界状态进行计算。

相反，少量输入就可以引出对后续状态的预测；新的输入继续到来，预测也随之继续变化。

例如，只看到一个物体的一角，就可能预期它其余部分的样子。继续移动视线时，新的观测会支持、改变或推翻这个预期。

因此，过程不是：

```text
完整观察结束 → 预测开始 → 行动开始
```

而是持续交叠的：

```text
接收部分信息 ↔ 形成后续预期 ↔ 接收新信息 ↔ 调整预期
                          ↕
                    自身行动与新的反馈
```

这只是文字流程示意，不要求真实过程按这些框框依次执行。

### 4.2 预测什么，不等于把未来补全

看见杯子刚滑出桌沿，预测可以具体到很不相同的程度：

| 这次预测的内容 | 不需要同时预测什么 |
| --- | --- |
| 自己的手接下来会伸出去 | 不必预演杯子怎么落、最后接没接住 |
| 杯子大致会往下，手上快要承重 | 可以没有清晰形象，也没有精确的落点和时刻 |
| 杯沿经过哪里、手指什么时候碰到它，甚至接下来一小段画面 | 可以很具体，但不意味着背景中的每件事也必须有预测值 |

这不是每次都要走完的三个步骤。如果系统只预测了伸手，就不必假设它其实已经生成了完整的未来，只是没有把画面解码出来。**“只预测伸手”说的是范围；“大概会往下”说的是精度；“不是一幅画面”说的是表示形式。** 三者可以各自变化。详细的画面预测是允许的特例，直接的动作预测也是。

预测也可以指向眼下尚未取得的信息：遮挡物后面再露出来的是什么，或半句话说完会听到什么。关键在于能否用后来的观察或行动检查这一次具体预期了什么，而不是能否还原世界的每个细节。

### 4.3 不把真实变化与预测混为一谈

必须区分：

```text
现实发生了：S_t → S_(t+1)

系统预测：根据已经获得的信息，对可能的后续状态形成预期。
```

仅仅写出 `Z_t → Z_(t+1)`，只说明内部发生了变化，还不足以证明这就是预测。

在一个具体实现中，需要能够说明：内部变化怎样关联尚未获得的观测或自身后续行为，反馈怎样影响它，以及这种联系怎样支持未见情境中的表现。

否则，理论会退化成“所有系统都在发生变化”，失去对智能的区分能力。

### 4.4 当次运行与长期学习

理论还需要区分当前状态改变和学习结构改变。

听到一句新的话，会改变当前可用于预测的状态；长期反复经历某类交互，则可能改变以后面对相似输入时的预测方式。

可以分别记作：

```text
当前运行：新输入改变 Z_t，并影响接下来的输出。

经验学习：反馈改变 θ，使未来相似条件下的预测发生变化。
```

这一区分避免了把“系统此刻考虑了新信息”直接等同于“模型参数已经更新”。本理论要求的是持续的经验影响与预测形成机制，而不是每一次状态变化都必须进行参数训练。

## 五、隐式结构是什么，不是什么

### 5.1 隐式结构是可复用的预测性组织

本理论所说的隐式结构，是经验使系统形成的一种内部组织：面对不同但具有共同特征的状态，它能够产生相应的后续预测。

例如，系统经历过许多物体被遮挡、再次出现的情境。以后只见到局部画面时，它仍可能对尚未看到的部分形成合适预期。

在本理论中，不必先假定系统内部储存了一条写着“物体持续存在”的规则。可以先研究它的状态怎样支持这种表现。

“隐式”也不等于完全没有结构。相反，系统需要有能复用、能受上下文影响、能在新组合中发挥作用的组织方式。

### 5.2 不把因果与逻辑藏回隐式层

本理论的强立场是：

> 隐式的首先是联合状态及其预测性转移，而不是隐藏起来的一套因果关系或逻辑命题。

因此，不能用“模型只是把因果图藏在了向量里面”作为不经检验的默认解释。也不能因为模型答出了一个推理题，就把“存在独立逻辑结构”当作直接观察到的事实。

网络完全可以学出有分工的计算。若它能稳定地追踪物体、比较两段话或检查矛盾，这些就是经验塑成的机制；“不是预装的”不等于“没有机制”。研究者也可以用逻辑描述一种非语言反应，而不必认为作出反应的系统自己已经在判断一个命题。

本理论真正押注的是：把一个说法当成理由、判断它能否推出结论，这种活动发生在语言层；承担它的仍是同一个预测网络，而不是另装的一台逻辑机器。这个主张需要证据，不能靠给网络内部的运算改名来成立。

### 5.3 “关系”作为研究语言与作为基本机制

研究者当然可以用“关系”“变量”“回路”等语言解释内部运行。本理论本身也不得不使用这些词。

区别在于：这些词可以是对运行过程的描述，不必同时被当作系统必须先拥有的认知原语。

例如，我们可以说“某部分信息改变了后续输出”。这是一句外部解释。它不要求系统在运行前先内部陈述：“这个信息与那个结果存在某种关系。”

理论反对的是把解释层的概念未经区分地放回机制层，不是禁止研究者使用描述语言。

### 5.4 隐式不等于永远无法理解

按照本理论，人类理解模型本身，也要通过观察模型的状态与行为，形成新的预测，并发展相应的语言。

因此，对隐式系统缺少经验，可能使现有语言难以准确描述它；但不能仅凭“高维”“分布式”或“隐式”，就断言它原则上不可研究。

可以区分三种目标：识别内部变化与行为的联系，用简洁概念概括这种联系，以及完整重现全部计算。前两者有用，并不要求第三者已经完成。

对于本理论，更重要的问题不是能否给每个内部方向起一个名字，而是：**这些解释是否帮助我们预测和改变系统行为，还是只给输出换了一套说法。**

## 六、学习、泛化与知识

### 6.1 学习不是给每种情况登记一个答案

一个系统可以记住许多完整情境，却仍然不能处理稍有变化的情况。

本理论关心的学习结果不是情境数量本身，而是：不同情境能否共同塑造一套可复用的隐式预测结构。

可以概括为：

```text
许多实际经历
    ↓
同一个系统反复参与预测与反馈
    ↓
内部转移组织发生调整
    ↓
在新情境中仍能形成有用预期
```

这里的泛化是学习结果与训练目标之一，不是一个单独安装的“泛化器”。

### 6.2 数据变化的意义

设想一个模型只见过红球向下移动，它可能把颜色与后续运动绑定在一起。

让它进一步经历不同颜色、不同运动方向、不同背景、不同遮挡以及不同操作，不只是增加完整场景的数量，也是在改变哪些预测方法能够持续成立。

关键不是让所有变量随机变化，而是让训练经历暴露重要差别：哪些变化只是背景，哪些变化确实伴随后续差异，哪些旧的预测方式不能迁移。

不过，多样性不会自动保证模型学出我们希望的结构。数据缺口、训练目标和容量分配，都可能使系统继续依靠不稳定的线索。这是具体实现必须面对的问题。

### 6.3 压缩可以是结果描述，不是额外前提

早期稿件使用过“压缩现实，再产生概念”的说法。按照后来的修正，这不是本理论所要求的过程。

本理论不需要假定系统先有一个压缩功能，把完整事件总结成概念，再交给预测器使用。

更贴近核心观点的表述是：

> 系统在预测中形成了能被重复利用的内部组织。观察者可以把某些结果称为压缩，但预测不必先经过一个独立的压缩操作。

同样，“看到一点就想到更多”可以是部分信息引起了后续预测，不必解释成系统先保存了一份完整事件，再取出它的压缩包。

### 6.4 知识处于哪里

在本理论中，“掌握某种知识”可以从功能上理解为：在相关条件下，系统能够形成适当的后续预期、语言输出或行为。

这不要求每条知识都以命题的形式储存在一个可检索的清单中。

但知识的语言化依然重要。通过语言，系统能够接触它没有亲自经历过的事件、比较不同陈述，并让已经形成的语言状态继续引出新的预测。

因此，知识既可以体现在不需要说出的熟练行为中，也可以体现在可以共享和重新输入的符号中。两者不必对应两种根本不同的智能机制。

### 6.5 涌现如何放在这个框架中

当已有的预测结构能够在新情境中共同起作用，系统可能表现出以前没有稳定完成的任务。

经验沉淀下来的不只是“上次的答案”，还可能是“以后怎样处理类似信息”。例如，同一组活动可以在一次遮挡中暂时保持杯子的身份；反复经历不同的遮挡，才可能把这种做法变成可迁移的能力。本稿称这种没有被逐项指定、却在学习中形成的分工为涌现。这里说的是个体经验改变网络，不是说个体练成的连接会直接遗传；演化与发育所提供的连接倾向，是另一个层次的问题。

但“由预测训练发展而来”仍然需要具体证据。不能因为某种能力后来出现，就自动断言它完全来自某一个训练因素，也不能把所有性能变化都解释成神秘的规模阈值。

## 七、语言如何从实践中自然产生

### 7.1 声音首先就是现实的一部分

语言的起点不是一个主体先看懂了世界，再决定用声音给它编码。

在现实运行中，人的发声、他人的动作、物体变化、身体感觉和社会回应本来就会共同出现。对于预测系统，这些首先都是经验的一部分。

某次经历可以被外部观察者描述为：

```text
看见某种东西 + 听见某个声音 + 看见别人伸手 + 自己获得某种身体感受
```

系统不必先知道其中哪一部分是“语言”。它只是在这样的共同状态中继续预测。

### 7.2 共同出现形成双向的预测联系

在反复的共同活动中，看到某种情境可能使某个声音变得可预期；听到那个声音，也可能使后续画面、动作或身体感受变得可预期。

用已经存在的“水”字作说明：

```text
杯子、倒水动作、声音“水”、口渴、喝水后的感受
```

它们可以在许多经历中以不同组合出现。系统由其中一部分，预测其余部分或后续变化。

这里不是先形成一个完整的“水事件概念”，再把“水”这个词贴上去。声音本身一直就在事件之中。

这个例子用于说明预测联系如何形成，不是声称最早的人类语言一开始就有现成词汇。对语言起源的更强主张是：最初没有固定词义的发声，也可能在反复互动中逐渐稳定地参与某些后续预测。

### 7.3 语言获得符号功能，但不是现实的完整替身

一个声音之所以获得符号功能，是因为它能够在特定背景中引出与其他状态有关的预期。

例如，即使此刻没有看见水，听到有关水的声音，也可能引出寻找杯子、等待倒水或描述某种场景的后续活动。

这可以被外部观察者称为“声音代表了水”。但在本理论内部，更基本的解释是：**这个声音已经能够接入过去经历形成的预测过程。**

因此，不应把词写成：

```text
一个词 = 整件事情的总括 = 完整现实的替代品
```

更准确的是：

```text
词是共同状态中的一个元素。
这个元素在当前背景中，可以引出许多后续预测。
```

词的这种作用可以被描述为提示、关联或局部代理，但不要求它包含或替换整件事情。

### 7.4 为什么同一个词可以引出不同东西

如果意义来自它在共同状态中的运行，那么一个词的后续作用就不应脱离背景固定不变。

听到“水”，在口渴时可能引出喝水，在漏水时可能引出关阀门，在化学课堂上可能接上分子式，在闲聊中可能进入一种比喻表达。

本理论不需要给同一个词指定一个足以穷尽全部用法的内部实体。它可以把这些差异理解为：相同的声音或文字元素进入不同联合状态，因而形成不同后续预测。

这也解释了为什么只背孤立词语，不等于掌握它在实际活动中的全部用法。

### 7.5 多个人之间的实际运行

语言不是一个孤立个体单方面完成的。一个人的发声会进入另一个人的状态，后者的反应又进入前者的后续状态。

例如：

```text
甲在某种情境中发声。
乙随后做出动作、回应或另一种发声。
甲得到新的反馈。
相似互动在不同场景中继续发生。
```

在本理论的解释中，能够被反复接续的声音与行为方式逐渐稳定下来。语言结构不是先由参与者共同完成设计，再开始使用，而是在实际使用与预测中形成。

这里的“稳定”不是永远不变。群体、处境和后续经历变化时，表达方式也可以改变。

### 7.6 不局限于声音

声音是最直观的例子，但理论不把声带当作语言的必要本体。

手势、表情、可见标记、文字和其他能够反复进入交互的信号，也可以参与类似过程。

关键不是材料一定是声音，而是某种状态元素能够反复出现、引出后续预测，并进一步与其他类似元素接续。

### 7.7 语言形成的顺序应怎样表述

本理论反对把语言生成写成以下目的论流程：

```text
先完整理解现实 → 决定概括现实 → 设计符号 → 用符号表达思想
```

它提出的替代解释是：

```text
现实运行中已经包含声音、动作和感知。
这些内容在共同经历中进入预测。
一些声音和标记逐渐引出稳定的后续预期。
它们与其他声音和标记的接续越来越丰富。
语言就在这种运行中形成。
```

符号功能是这一过程的结果，不是它开始之前必须存在的设计方案。

## 八、语言如何成为自行运行的预测空间

### 8.1 从声音连到现实，到声音连到声音

最初，某个声音主要在具体情境中出现，并引出相关的后续活动。随着交流持续发生，声音前后本身也出现了可以学习的接续方式。

于是，系统既可以从画面预期声音，也可以从声音预期另一个声音；既可以从文字引出场景预期，也可以继续产生另一段文字。

这种关系可以示意为：

```text
现实中的部分信息 ↔ 声音或符号
声音或符号 ↔ 其他声音或符号
```

“互相预测”不表示两个词自身是预测主体，而表示同一个系统能够在不同上下文中，借助其中一个元素形成对另一个及其后续内容的预期。

### 8.2 自己产生的语言成为新输入

当系统说出一句话，或在内部继续一段语言活动时，这一产物又改变了当前状态。

后续预测不再只取决于最初的问题，也取决于已经产生的语言。

```text
当前状态 → 产生语言片段
语言片段进入新的当前状态 → 继续产生语言片段
新的片段再次进入后续状态 → 继续运行
```

从外部看，这可以表现为解释、联想、推理、写作或自问自答。理论不要求为这些现象分别设置一种新的基本操作。

关键变化是：**预测的结果可以成为下一次预测的条件。**

### 8.3 “自行运行”不等于彻底脱离现实

语言可以暂时不依靠正在发生的对应场景继续运行，但这不等于它从未受过现实影响。

说“明天到仓库检查设备”时，仓库和检查动作不需要此刻出现在眼前；然而，这些表达如何接续，与过去的实际经历、交流、操作和反馈仍然有关。

语言也不是脱离物理世界的另一个实体。发声、文字、阅读以及内部活动，都仍然是实际系统的状态变化。

所以“语言世界”表示一种可以持续参与预测的符号状态范围，不表示产生了一个在本体上独立的宇宙。

### 8.4 为什么把高级智能放在语言层

本理论认为，语言使预测能够反复进入可以保存、共享、重复接续的符号状态，从而不必每次都重新经历相应的外部事件。

一个问题可以被说出来，回答又成为新问题的条件；一个假设可以持续保留，多步内容能够围绕它继续展开；别人的经历可以以语言形式进入当前系统。

作者主张的不是“有了语言，原本就有的高级判断会表达得更好”，而是：**高级智能只存在于语言层。基本功能仍然只是预测；当它预测的内容包括说法、理由、异议以及接下来的回答，因果解释、逻辑和是非判断才成为系统所做的事。** 这里的语言不要求实际出声。手语、书写或数学符号在能承载并接续这些内容时，同样可以起这种作用；不是每个内部编码都因此叫语言。

看到杯子倾斜，伸手接住，甚至换一只手也能接住，都可以是灵活的非语言预测。“是我碰倒的，还是桌子晃了？如果我根本没碰桌子，原先那个理由还成立吗？”这是另一件事：先前的解释本身成了可以保留、质疑和撤回的内容。区别不在于动作难不难，也不在于最后是开口回答还是用手指出答案。后一种能力是否离不开语言，是一个可以检验的问题，不能靠把“高级”定义为“说出了话”来回答。检验办法见第十五节。

### 8.5 复杂化不是必然越说越正确

语言可以产生新的语言组合，但不能因此推出：只要持续生成，知识就必然增加，结论就必然更正确。

同样的递归过程也可能重复、偏离问题、自相矛盾，或者把一个错误前提不断扩展。

因此，“越预测，越复杂”更准确地表示语言活动具有形成更复杂状态的可能性。哪些复杂结构能够保持有效，还取决于实践反馈、交流中的修正、形式约束以及训练经历。

语言产生更多内容，与语言形成更可靠的知识，是两件需要区分的事。

### 8.6 智能上限的两种来源

沿着作者后续的观点，可以区分两类限制。

一类是预测结构本身的限制：系统是否能保持足够长的历史影响、处理复杂条件，并在未见情境中形成可靠预期。

另一类是语言状态空间的限制：现有表达方式能否稳定区分问题、保留中间内容，并支持继续操作。例如，一个新符号或新表示法可能使原本难以持续处理的问题更容易展开。

因此，提高智能不只意味着扩大内部容量；也可能意味着改变它所能接触和运行的语言、符号或交互形式。这个判断是本理论提出的研究方向，不是关于任何特定模型的性能保证。

## 九、因果、逻辑与推理处于哪一层

### 9.1 核心立场

本理论最有辨识度的主张是：

> 对一个动作会带来什么后果形成预期，不等于已经判断“它是原因”。本理论把可陈述的因果、能否推出结论的判断，以及对是非的评判放在语言层；支撑这些活动的仍是隐式联合状态转移预测。

它不同于“内部先有一套因果模型，然后语言把它翻译出来”。也不同于“内部先按逻辑规则推完，再把答案组织成一句话”。

本理论试图把这些高级表现也解释为预测在语言状态中的持续运行。

### 9.2 因果语言怎样接入预测

在反复经历与交流中，人会接触到某些行动、变化和表达方式共同出现的情境。

例如，改变开关状态、灯的变化、他人的说明以及后续操作，可以一起进入学习过程。“开关”“亮了”“因为”“所以”等语言元素，也在这种实践与交流中参与预测。

后来，人在没有当前灯具的情况下，也可以说出关于这些情境的解释，并进一步预测不同操作之后会发生什么。

理论的重点是：这些语言与实践一起运行，而不是系统必须先找到一个名叫“因果”的内部对象，才有可能形成相应表达。

### 9.3 先后规律与干预问题仍需区分

把因果语言解释为预测过程的产物，不等于把所有先后关系都宣布为正确的因果关系。

设想一个系统总在红灯亮起之后听到警报。它可以学会从红灯预测警报。但“只把红灯改成绿色，警报是否停止”是另一个需要经验或假设支持的问题。

完全可能有两个不同装置：一个由红灯电路触发警报，另一个由共同控制器分别控制红灯和警报。原先的记录可以相似，改变红灯后的结果却不同。

因此，本理论不能用“底层都是预测”抹掉这些任务的区别。它需要解释：**什么样的交互经历，能够使同一个预测系统在这些不同问题上形成恰当的后续预期。**

这一点可以不要求预置显式因果图，但不能靠把所有观察都统称为状态转移来自动解决。

### 9.4 逻辑语言如何继续运行

考虑一个简单的符号情境：

```text
所有 A 都属于 B。
x 属于 A。
所以，x 属于 B。
```

按照本理论，系统可以在语言经验、符号操作和纠错中形成这种稳定接续，不需要每次先调用一个独立的通用逻辑执行器。

这种解释并不意味着系统只记住了某一句固定的话。真正需要解释的是，它是否能在替换名称、改变表达、增加无关内容或嵌套条件之后，仍然产生符合相应规则的结果。

如果只能续写熟悉句型，遇到新组合就失效，它说明的是局部语言预测能力，而不是充分的逻辑泛化。

### 9.5 高频输出不等于有效推理

逻辑有效性不能简单定义成“这句话经常跟在那句话后面”。

例如：

```text
如果 A，则 B。
现在 B 成立。
所以 A 成立。
```

这段话可以听起来顺畅，但其结论并不由给定前提保证。只需存在“B 成立而 A 不成立”的情形，就能看出问题。

本理论要解释的，是预测系统怎样在学习中形成能遵守这类区分的语言行为，而不是取消这类区分。

换句话说：**对推理能力形成机制的预测解释，不等于把推理正确性的标准改成输出概率。**

### 9.6 “产生逻辑”需要解释到什么程度

理论提出，逻辑可以在语言实践与预测中形成，而不是先天预设为独立机制。要把这一主张发展成科学解释，还需要说明：

- 对新的符号和组合，为什么仍能遵守相关约束；
- 当前提发生变化时，为什么应当改变结论；
- 如何从具体接续发展出可稳定使用的更一般形式。

这些是本理论要回答的问题，不能由“语言开始相互预测”这一句话直接代替。

### 9.7 不需要断言现实违反逻辑

“逻辑不是必须预置的底层智能机制”，不等于“现实不受任何约束”，也不等于“逻辑关系全部无效”。

本理论可以把语言关系看作运行中形成的结构，同时承认不同表达会受到不同类型的约束：关于经验的陈述需要面对观测，形式推演需要符合给定的规则与定义。

对这些约束的来源进行解释，与否定这些约束存在，不是一回事。

## 十、行动、目标与探索

### 10.1 自身动作可以是这次预测的全部内容

作者对行动的核心表述是：

> 行动也是模型的一部分，就是预测自己接下来要干什么。

因此，理论不把智能分成一个只看世界的预测器，再加一个站在预测器之外的决策者。

在当前状态中，身体姿势、眼前的变化、过去行为留下的结果，有时还有一句话，都可以影响预测。接下来被预测的可以只有“我会抬手”。人在这种情况下不必看见一幅自己抬手的画面，不必先断言“抬手是对的”，也不必意识到自己作了预测。这是作者解释人和动物行动的假说，不是从动作外观就能读出的事实。

### 10.2 预测如何参与真实动作

最短的闭环可以是：

```text
当前画面、身体和过往经历 → 预测自己下一步抬手 → 运动通路使手抬起
                         ↑                         │
                         └──── 新的视觉和身体反馈 ──┘
```

预测自己的动作并接到运动通路，与想象别人抬手、或设想“如果我抬手”不同。后二者可以留在内部，不必带动自己的手。这个区别需要由所处情境、网络活动与输出通路实现，不必再假定有个内在观察者审批每一个动作。

同一网络也可以预期“拉 A 会带动电池舱”，让这个预期影响自己的下一动作；甚至可以展开几种较完整的未来再比较。**先看后果是否合乎目标，是可以专门研究的一条行动路径，不是所有行动必须经过的关卡。** 反过来，只看到模型输出了“拉 A”，既不能断言它在内部预演了后果，也不能断言它没有利用任何预期。

### 10.3 目标不是站在系统外面的命令者

一个目标可以以语言、身体状态、记忆或其他形式进入当前联合状态。

例如，“把杯子拿过来”这句话、杯子的位置、过去的操作经历，以及当前身体状态，共同参与后续行为预测。

本理论不要求再引入一个独立的“我”，站在整个系统之外比较方案并发布决定。所谓“为了某个目标而做”，可以是对包含目标相关信息的预测过程的外部描述。

但这不意味着只要把目标写进输入，系统就必然会完成它。**目标的出现如何改变后续行动预测，取决于学习经历与反馈组织。**

### 10.4 最可能的动作不一定是最好的动作

这是行动部分必须面对的关键问题。

如果训练经历中同一情境下经常失败，单纯复现最常见的后续行为，也可能复现失败。预测自己“通常会怎样”，不自动等于预测出“这次应当怎样才能成功”。

本理论需要在统一框架内解释两者如何连接。例如，成功经历、纠正反馈、目标条件和训练中的选择压力，可以改变哪些后续行为被系统稳定地产生。

这些过程可以仍然通过改变预测结构来实现，但不能从“行动也是状态”直接跳到“行动就会正确”。

这是一项待解决的机制问题，不是必须另设独立主观决策者的证明。

### 10.5 危险与探索的解释

按照这套理论，面对危险时发生的逃跑，不一定需要被解释为一个额外主体先作出“我要活下去”的命题判断，再下达逃跑命令。

危险相关信息、身体变化、过去经历及后续动作，可以共同形成一个实际运行的预测过程。外部观察者把它概括为“为了避险而行动”。

探索也可以被放回同一个框架：未知情境、此前探索的经历、身体状态和可能的后续反馈，共同影响“接下来自己会做什么”的预测。

不过，这些解释还需要回答：何种学习经历会形成持续探索而不是回避或停滞。理论不能仅把行为叫作预测，就认为已经解释了它为何出现。

### 10.6 规划不是必须存在的独立基本机制

一段包含未来语言、自身行动和环境变化的连续预测，可以在行为层表现为规划。

```text
当前情境 → 准备工具 → 到达位置 → 执行操作 → 获得反馈
```

工程上可以把这段过程交给一个名叫“规划器”的模块；本理论讨论的则是：它是否必须是一种不同于预测的基本智能机制。

本理论的答案倾向于否定，但仍需用实际任务证明预测过程能够保持目标、处理失败并在较长跨度上继续运行。

## 十一、思考、自我与意识的解释位置

本节区分三件事：预测内容回流可能有什么作用，它在人体里可能怎样发生，以及作者由此提出的自我意识假说。前一件成立，不能自动证明后两件。

### 11.1 思考是内部状态继续参与后续预测

一个系统不需要等到外界每发生一步，内部才运行一步。

自己产生的语言、图像预期、动作预期和记忆影响，都可以成为后续状态的一部分，继续引出新的内容。

在这一框架中，“思考”不是预测之外新增的一层，而可以被理解为内部产物不断成为后续预测条件的运行过程。

### 11.2 心声假说：预测的内容回到感觉一侧，思路因此能接下去

默念“钥匙还在……”时，没有人真的在耳边开口，前半句却可以像刚听到的话一样，把“外套口袋里”带出来。作者对心声的猜想是：脑内预测出的声音、画面或身体感觉，从产生它们的活动传出，又回到感觉一侧，像新输入一样参与下一次预测。这样，一次短暂的活动结束以后，思路仍能往下走。所谓“错觉”不是否认人确实有仿佛听见的感受，而是说不必有另一个正在里面说话、听话的“我”。

这里有两个不能互相替代的问题。**功能上**，上一步的产物能不能重新作为输入，延长思维？可以在人工系统里接通、切断回路来研究。**生理上**，作者提出的返回是否真的经过相应的感受器？返回脑内感觉通路，与信号到达眼、耳等外周感受器后再传入，不是一回事。如果主张的是后一条路线，就需要能辨别两条路径的生理证据。模型有循环、能续出一句话，不能证明人体采用了其中任何一条。

### 11.3 自我相关内容同样可以被预测

“我是谁”“我刚才做了什么”“我接下来会怎样”，都可以成为当前状态中的语言或非语言内容。

本理论因此不预设一个脱离自身状态转移的额外主体。对自我的描述、对自身行为的预期，以及关于自己预测是否可靠的表达，都可以在同一系统内出现。

作者更强的立场是：**“人不存在自我意识。”** 按作者的解释，平常被归给一个内在“我”的声音、画面和感觉，本身就是预测及其回流的内容，并非另有一个自我在接收和指挥。对“这是我的手”“我刚才做了什么”形成表征，或报告自己有心声，与承认一个独立主体是两回事。

也要保留反方向的界线：解释一个动作时用不到内在决策者，并不能据此证明自我意识不存在。这里没有把强命题悄悄改成“控制系统不必设中央控制器”，也没有把它写成人体实验的结论。为什么会有疼痛或第一人称感受，仍不能凭一个行动模型的表现来回答。

### 11.4 不把解释主体重新放回来

在叙述中容易说“系统知道该做什么，所以选择了最好的未来”。这类话可以作为行为概括，但不能代替机制。

本理论始终追问的是：当前状态、学习留下的结构和持续输入，如何形成下一步语言与行为。

如果每到困难处就加入一个“真正理解并作出决定的我”，理论就重新引入了它原本试图解释的东西。

## 十二、科学与现实的关系

### 12.1 语言即世界的适用含义

“语言即世界”在这里不是说现实由语言随意创造，也不是说人只能拥有语言经验。

它强调的是：当人要明确陈述对象、关系、条件、推论和理论时，能够共同讨论和继续操作的世界，很大程度上已经进入语言与符号的运行。

语言不是悬空的容器。它来自现实活动，并在后续实践中继续受到现实约束。

所以可以同时说：

```text
语言影响人能够怎样继续描述和预测世界。
现实反馈影响哪些语言表达能够持续有效。
```

### 12.2 内部结构不必是现实的原样复制

一个预测系统可以在有限任务中给出有效结果，而不需要逐项复制被预测对象的全部组成。

因此，本理论不要求内部隐式状态与现实在结构上完全同一，也不要求语言中的每一个概念都有一个一一对应的现实基本实体。

但“不要求完全同构”不能被扩大为“内部绝不可能保留任何现实结构”。为了在某类任务中持续有效，系统可能需要保留相关差别与约束。

本理论要避免的是把成功预测直接等同于已经发现了现实的最终本体。

### 12.3 科学不是任意语言游戏

如果两套表达对同一问题给出不同预期，它们可以面对同样的观察、操作与结果。

语言能够任意组合，不意味着现实会任意配合。

科学在本框架中的位置，是把语言预测不断接回公开的实践过程，使陈述、条件、操作、结果和修正能够被其他人继续接续。

可以概括为：

```text
实际经验
    ↓
语言与符号中的继续运行
    ↓
形成可以面对现实的预期
    ↓
观察、操作与反馈
    ↓
原有语言和预测方式被保留、限制或修正
```

这解释的是科学如何嵌入预测与语言的循环，不是把实验、测量和证明都取消，只剩下流畅表达。

### 12.4 数学与科学需要区分约束来源

数学陈述可以在给定的定义与规则中讨论推导是否成立；经验科学陈述还要面对实际观测。

本理论可以尝试解释人如何在符号预测中学会遵守这些约束，但不能把二者都简单改写成“现实里经常出现，所以正确”。

一段数学推导在语言空间中运行，不等于其正确性仅由句子出现频率决定。一个科学故事讲得连贯，也不等于它对现实的预期已经成功。

### 12.5 理论必须允许自己被修正

联合状态转移预测理论本身同样是一套语言描述。它不能因为解释了语言的来源，就豁免于清晰定义、经验比较和反例检验。

它的价值应当体现在：是否帮助区分模型、组织训练、提出实验，并解释原本难以统一的现象。

如果任何结果都能被重新命名为“还是预测”，却不能改变任何实际判断，那么它仍只是宽泛的描述框架，还没有成为有区分力的智能理论。

## 十三、统一人工智能的架构含义

本节是由理论导出的工程构想，不是在宣称某个现有模型已经验证了整套理论。

### 13.1 不同模型可以预测不同形式的状态

从本理论出发，语言、视觉、视频、三维和动作模型的区别，首先在于它们接触什么数据，以及什么样的后续内容得到训练约束。

| 训练内容 | 在本理论中的位置 | 不能仅由这种训练自动推出的能力 |
| --- | --- | --- |
| 语言、代码和形式符号 | 学习符号在上下文中的接续与共同约束 | 不自动保证掌握未接触的物理操作 |
| 静态图像与相关条件 | 学习可见状态的结构及条件联系 | 不等于已经学习真实时间中的运动与反馈 |
| 视频和时序感知 | 学习随时间变化的观测与隐状态 | 不自动保证形成可靠的行动后果预测 |
| 三维场景、深度或高斯表示 | 提供空间状态及其可观测形式 | 静态表示本身不等于状态转移模型 |
| 画面、任务与下一次实际动作 | 可以直接学习从情境预测自身动作，不必把下一帧作为目标 | 只看动作成绩，看不出它是否预期了外界后果 |
| 包含行动及其后果的交互轨迹 | 还可学习“同一操作在不同经历后会带动什么” | 能预测后果，不保证行动就会用上它 |
| 多模态持续交互 | 让多种内容在同一过程中相互预测 | 不保证仅靠混合数据就实现了有效统一 |

这不是对技术路线作固定高低排名。同样的统一原则，可以在不同任务中产生不同的架构取舍。

### 13.2 从希望获得的能力反推数据

按照作者后续提出的设计原则，应该先明确想要什么能力，再反推应该让系统学习什么状态变化。

要研究语言推理，就给系统能接续、质疑、修正说法的经历。只想学习熟悉窗口的下一次点击，画面和实际操作就提供了对应的训练信号；若想知道模型是否预期点击后会打开哪个窗口，就要另有真实后果可供核对。对机器操作也一样：模仿操纵杆动作与预期铲斗遇阻，并不是同一道训练题。

“都是预测”不意味着数据内容可以互换，也不意味着所有算法同样适合每种任务。

更准确的设计原则是：

> 统一的是对智能机制的解释，不是抹去数据形式、表示方式和训练条件之间的实际差别。

### 13.3 共享隐式空间的真正含义

理论所期待的统一模型，不只是让一个语言模型把文字命令发送给另一个世界模型。

更深的统一是：视觉、语言、身体、记忆和动作信息能够共同改变后续预测，任何一种内容都不必被永久隔离在只能由单向接口访问的系统之外。

可以用文字示意：

```text
此刻可获得的信息 + 过去交互留下的影响
                  ↓
           共同的隐式状态
                  ↓
   这次预测：一个动作、一句话、一种感觉，
          或其中几项与外界变化一起
                  ↓
 可执行的输出作用于世界；新的观测进入下一次预测
```

共享指经历能改变同一网络后面的工作，不是指必须有一个固定长度的向量或一段能还原全部模态的隐藏影片。一次试探可以留下“这两部分会一起动”的经验：下一轮只用它来预测自己拉哪个把手，就不必同时输出两舱的运动画面。

### 13.4 统一不等于完全同质

视觉、语言和控制信号可以具有不同的编码与解码方式。模型也可以使用多个尺度、局部子空间和不同接口。

这些工程区别不必意味着存在不同本质的智能。判断是否符合本理论，应该看它们是否进入可共同学习的预测过程，以及彼此信息是否真正影响后续状态。

因此，不能把“用了行动输出头”直接判定为不够统一，也不能把“所有内容都写成 token”直接判定为已经统一。

模块名称和数据包装都不是充分标准。

### 13.5 未来预测不只限于紧邻下一步

理论中的“后续”可以跨越不同时间尺度。实际训练可以约束下一次观测，也可以约束更远的任务阶段、缺失内容和不同模态之间的后续对应。

例如：

```text
当前画面和操作 → 下一次界面变化
当前任务与历史 → 后续动作序列
当前语言片段 → 后续语言与场景预期
部分观测 → 继续观察可能得到的内容
```

这是为了使训练内容覆盖理论声称的能力，不是向核心机制追加一种神秘的长程认知。

但长跨度预测也会面对误差积累和不确定性，不应被写成必然精确展开的单一未来。

### 13.6 隐式状态必须受到现实任务约束

如果只要求模型预测自己生成的某个内部向量，而没有其他约束，那么一个始终输出同一状态的系统，也可能在这种自我对照中表现得很好。

因此，工程实现不能把“预测隐状态”本身当作充分目标。它需要通过实际观测、语言接续、操作结果或其他明确任务，保证内部状态保留了有用的信息。

可以采用不同的训练目标来实现这些约束，但它们应服务于同一件事：使预测对实际后续内容有区分力，而不是只让模型内部形成容易自我满足的循环。

### 13.7 三维与高斯表示的位置

三维、高斯、图像或深度，可以在本框架中作为世界状态的输入形式、监督形式或输出形式。

它们不是智能本身，也不必成为统一隐式状态的唯一形态。

假设训练时要求模型表达当前与未来场景，这可以成为约束内部预测的办法；但是否需要在运行时完整重建场景，要由任务决定。

同时，一段看起来逼真的未来场景，不能仅凭视觉效果就被当作准确的力学或控制结果。所需预测究竟是画面、位置、受力还是任务完成，必须在训练与评价中明确。

### 13.8 生成算法的步骤不等于现实的时间

理论允许不同计算方法实现预测，但不能把所有算法内部迭代都直接解释成世界时间。

例如，一个生成过程从粗略结果逐步修正为清晰结果，其内部步骤不一定对应现实的前后事件。

因此，“算法在改变状态”“算法在生成一个状态”与“算法在预测真实交互的后续状态”，应当分开描述。

这个区别不会破坏统一观点，反而有助于明确哪些训练真正约束了世界变化，哪些训练主要约束了状态的表现形式。

## 十四、两个完整应用例子

以下是帮助理解理论的假想场景，不是已经执行或验证的实验。

### 14.1 桌面操作：看到画面，可以只预测下一次点击

用户提出：“把这个文件移动到目标文件夹。”

当前状态中同时包含任务语言、窗口画面、鼠标位置、过去的操作信息以及系统对界面的经验。

按照本理论，不必先假定一个独立规划主体把需求翻译成完整计划，再交给一个完全不同的动作智能。系统可以在共同状态中预测自身后续操作，并持续接收反馈。

```text
任务语言 + 当前界面 + 操作历史
    ↓
预测自己下一次拖动文件（可以是唯一输出），并执行
    ↓
实际界面发生变化
    ↓
新画面与原任务共同进入当前状态
    ↓
预测接下来自己会做什么
```

如果出现一个没有预料到的弹窗，理论要求新的输入能及时改变后续预测，而不是盲目执行最初生成的完整序列。

若两个文件夹长得很像，系统也可以先预期“松手后文件会出现在左边”，再据此调整落点。两种走法都符合理论。前一种不是因为少画了未来就不算预测，后一种也不是因为画出了未来就一定更可靠。

但系统是否真的把文件移对，仍需要从实际结果判断。能够描述正确步骤，不等于能够在真实界面中完成任务。

### 14.2 铲装作业：隐式空间不只包含画面

考虑“从料堆取料并送到指定位置”这一任务。

可进入当前状态的内容包括任务语言、相机画面、设备姿态、铲斗位置、控制输入、受力反馈及此前的运动历史。

操作者感到阻力上升，接下来可能只预期“手要回收一点”，也可能预期铲斗将被顶起。两者都不要求他在脑内算出每颗石子的轨迹。这不是说笼统预期总够用：若要区别是斗刃碰到硬底，还是料堆本身更紧，经历里就得有能区分两者的线索。

不必先要求模型内部拥有名为“颗粒因果律”的显式规则，才允许它学习铲斗插入之后的状态。但它也不能仅凭看到相似视频，就被认定已经掌握真实受力和作业条件。

如果训练内容只有外观变化，它可能主要形成外观预期。要使受力、阻滞、装载量与后续操作进入同一个预测体系，就需要相应的观测、交互或监督。

这一例子说明：**理论上的机制统一，不会取消具体任务所需要的信息。**

## 十五、可检验命题与实验区分

15.2–15.6 是五个研究问题，不是五项已经完成的实验证明。15.8 单列项目中已有的冻结实验，说明它们各自回答了其中哪一小部分。

### 15.1 把理论主张变成可比较的问题

“任何能力都只是状态转移”太宽，难以形成有效比较。

更有区分力的问题是：在事先约定的数据、资源和任务条件下，不预置某种高级认知模块的预测系统，能达到什么能力；哪些能力依赖语言交互；哪些能力受益于共同隐状态；失败发生在什么条件下。

实验之前需要明确能力标准，不能在看到结果之后，把所有成功都称为“预测”，把所有失败都归因于“规模还不够”。

### 15.2 问题一：没有预置词义时，符号功能能否形成

让多个预测系统在同一环境中活动，并允许它们产生可被其他系统接收的信号。不预先指定哪个信号必须对应哪个对象，也不直接给出完整符号词典。

观察信号是否在重复交互中形成稳定作用，是否能够在对象暂时不可见时引出合适的后续行为，以及能否迁移到新的场景组合。

需要对照随机信号、打乱时间对应的信号和有正常交互反馈的信号。

如果信号只能在训练场景中触发固定反应，而不能随背景变化形成可复用的作用，那么它尚不足以支持完整的语言形成主张。

即使出现稳定通信，也只能支持符号功能可以从这类训练中形成，不能立即证明自然语言的全部起源过程。

### 15.3 问题二：判断是否离不开语言

比较现实经验相近、训练资源可比的系统，其中一组可以持续接触和产生可重新输入的符号序列，另一组不具有这一条件。

除新组合、条件保持和多步任务外，更有区分力的是这样一道题：系统先依据一条线索在两个解释之间作选取；新证据否定了原先的理由，但不改变眼前操作的收益。看它是否只撤回依赖这个理由的结论，保留不相关的结论，并把这一区别迁移到新情境。可以用指选或操作作答，不要求开口，也不能仅靠模仿否定句得分。

如果允许语言接续的一组占优，支持的是语言在这些条件下有用，不是语言必不可少。如果另一组既未获得语言输入，也没有学成可识别的语言系统，却仍能稳定作出上述区分，作者关于语言必要性的主张就遇到了反例。实验前要约定怎样识别语言活动、怎样排除只记住动作顺序的解法；不能等对照组成功了，再把它的一切内部活动叫作语言。

### 15.4 问题三：统一状态是否优于松散拼接

比较共同训练、信息可以双向进入预测的体系，与主要通过固定接口交换结果的体系。

保持数据接触范围、计算预算和输出要求尽量可比，考察跨模态纠错、缺失观测、语言指令改变后的行为调整，以及新情境迁移。

若统一结构占优，支持的是某种具体统一设计在相应条件下有效；若没有优势，需要检查统一是否造成容量竞争、信息损失或训练冲突。

本理论不应预先把任何共享参数方案都宣布为最优，也不应把所有模块化设计都排除。

### 15.5 问题四：能完成任务，与确实依靠后果行动，是不是一回事

至少要把两件可独立改变的事写清：**训练时有没有要求预测外界后果；执行时可不可以利用这种后果预期。** 只从画面、目标与经历学习下一动作，是“只训练动作预测”的对照，不是“非 JSTP”。另一组可在同一权重里兼学动作与后果，并保留直接动作通路。应尽量匹配两组可见的经历、容量和训练预算。

冻结权重后，先固定同一次试探，只换训练未见的目标，实际执行并分别记分。这检验同一经历能否服务于不同任务，不足以说明后果参与了行动。再固定真实经历、目标和可执行动作，只改变网络中已被独立校准为对应某种物理后果的活动；直接通路保持原样。若只在这种后果理应改变操作时才定向换手，而等幅的无关改变很少换手，就有了关于这条路径的证据。故意给错预期甚至可能把原本正确的动作带错：对任务是失败，对识别机制却有用。

反过来，即使一次干预没有改变动作，也只说明这一实现没有显示出对**被改的那部分预期**的依赖。不能把它解释为网络没有预测自己的动作，更不能据此否定一切隐式预期。

### 15.6 问题五：独立逻辑或因果模块是否必要

在约定任务与资源下，比较纯预测学习的方案，以及加入显式逻辑规则、因果图或专门规划结构的方案。

如果前者在未见符号、新组合和干预变化下取得可比结果，支持的是：这些显式模块在该范围内并非必需。

这仍然不直接证明前者内部没有任何可被描述为逻辑或因果计算的组织。要支持更强的内部结构主张，还需要明确识别标准与内部干预证据。

同样，如果显式模块更有效，也不自动证明它是所有智能的基本原语。它可能只是更适合这一数据规模和任务范围的实现。

### 15.7 如何避免无限后退

对每个实验，应当事先规定训练条件、可增加资源的范围、评价任务和什么结果会改变判断。

有限实验不能证明某种架构在所有可能规模下必然不行，但可以推翻一个具体的资源范围预测，也可以显著降低某条路线的实际可信度。

因此，理论最好同时提出两种命题：一个范围较大的机制假说，以及若干受明确条件约束的工程预测。后者能够在较短研究周期中得到实际反馈。

### 15.8 已有实验：哪些区分已经在模型上做出来

以下是不同任务中的记录，不是同一张能力排行榜。

| 具体问了什么 | 冻结模型的记录 | 可以得出什么 |

## 十六、当前边界与未解决问题

### 16.1 只有转移，不等于已经解释了预测

一般动力系统也会不断转移。理论仍然需要给出区分：什么样的内部状态可以称为对尚未获得信息的预测，什么样的反馈表明它真正学到了可泛化的内容。

这是核心概念的操作化问题，不是一个可以忽略的词语问题。

### 16.2 没有独立模块，不等于内部没有结构

本理论否定的是“每种能力都必须先装一套同名机器”，不否定同一个网络后来学出不同的计算方式。一个对边界归属敏感的回路，如果由没有分割标签的预测训练形成，而且干预它会有选择地损害对物体的预测，它正是理论希望解释的结果，而不是反例。

反过来，若在明确定义的训练与资源条件下，只有预先给出对象身份才能学会追踪，那么“本实验的预测经历足以产生分组”就没有成立。不能拿“神经网络原则上能表示物体”替这次实验过关。

### 16.3 语言有帮助，与高级判断离不开语言，证据不同

作者并不主张全部智能都需要语言；伸手、躲避、追踪和预期干预后果都可以不经过语言。真正有争议的是：在没有语言活动的情况下，系统能不能仍把一个理由当成理由，对它表示反对或据它修正别的判断。语言回输提高某道题的成绩，不足以回答这个必要性问题。

尤其需要避免把“语言”无限扩张为“任何有结构的内部活动”。否则“高级智能需要语言”会成为定义上的重复，而不是关于实际系统的命题。

### 16.4 行动有效性需要学习来源

把行动纳入预测，是一个统一表述；使预测出的行动可靠，则需要解释训练经历如何区分成功、失败与无关后续。

本理论可以不预设独立的意志主体，但仍需说明行为偏向、探索和长期任务保持怎样形成。

### 16.5 局部世界与智能理论的证据不能互相冒用

统一预测系统可以有效工作，并不证明现实底层一定由异构局部世界组成。

同样，局部世界作为哲学框架具有吸引力，也不证明纯预测机制足以产生全部高级认知。

两者可以兼容并互相启发，但需要分别说明各自的命题与支持材料。

### 16.6 当前最准确的理论地位

这是一套具有明确统一方向的智能假说：它试图减少预置认知机制，把语言、世界和行动放回同一运行过程。

它的价值不应由“听起来能解释一切”衡量，而应由它能否指导更清楚的设计、提出有区分力的预测，并在反馈中允许修正来衡量。

## 十七、最小形式化与核心命题表

### 17.1 形式化的目的

下面的表达是对理论的一个实现中性草案，不是唯一正确的模型结构。

它保留四个不同概念：现实的实际变化、系统接收到的信息、内部状态的更新，以及对尚未得到内容的预测。

### 17.2 现实与局部观测

```text
现实变化：
S_t → S_(t+Δ)

系统获得：
O_t = 当前能够取得的部分信息
```

这里不要求系统拥有完整的 `S_t`，也不要求 `O_t` 单独足以确定未来。

### 17.3 内部状态更新

```text
Z_t = Update_θ(Z_(t-1), 新观测, 自身先前输出的影响)
```

`Update` 是对运行过程的记号，不是新加入的高级智能模块。

它可以持续发生，不需要等待每种输入同时到齐。历史影响可以通过内部状态保留，不要求每一步都重新读取全部过去。

### 17.4 从联合状态预测哪一部分变化

```text
Z_t：当前观测、自身状态和历史影响共同形成的内部状态
Y：这次预测所涉及的后续内容
q_θ(Y | Z_t)：从当前联合状态对 Y 形成的预期
```

例如，在时间跨度 Δ 内，`Y` 可以只是“我的手开始抬起”，可以是“杯子大致向下”，也可以是“手的运动与杯子位置的共同变化”。如果这次确实形成了画面预期，画面也可以是 `Y`。新观察能否印证“向下”，与能否逐像素还原一帧，是两种验收。

这个记号没有在网络中增设一个“挑选 Y 的模块”；它只是让研究者说明这次谈的预测究竟是什么。没有纳入 `Y` 的量可以根本没有被预测，不必先生成完整的世界分布，再删去其他分量。`q` 也不是强制输出概率表：一个动作、一个粗方向或一个可由后续反馈核对的隐式预期，都可以是实现方式。

### 17.5 输出与再输入

```text
语言相关输出 → 成为后续语言或感知状态的一部分

关于自身下一动作、接入执行通路的预测 → 身体或接口行动 → 新反馈进入状态

对他人动作、假想动作或外界变化的预期 → 可以不执行，可在后续观测中被支持或修正
```

这是“语言自行运行”和“行动属于模型”的共同位置：系统自己的产物，不停留在模型之外，而继续进入后续状态。

### 17.6 学习

```text
预测与实际后续之间的差异，以及任务相关反馈
    ↓
改变长期结构 θ
    ↓
改变以后相似与新情境中的预测
```

对人工实现，参数优化可以是实现学习的一种办法；本理论不要求把特定优化器、损失函数或训练阶段顺序当作智能本体。

同样，存在一个统一的解释目标，不意味着工程中只能采用一个数值损失。不同输出约束可以共同服务于有用的联合预测。

## 十八、完整理论的凝练表述

### 18.1 一句话版本

> **智能从自身与世界的联合状态出发，预测接下来会发生的某些变化：它可以只预测自己伸手，也可以预期手和杯子怎样一起动；按本理论，只有当预测在语言中继续展开、能把一个理由接到另一个判断上时，才出现高级智能。**

### 18.2 展开表述

作者把世界理解为联合事物的转移。杯子、手和桌面在同一个过程中变化，却不必永远一起动。神经网络中可以分别变化、又相互连接的单元，给了系统表达这种差别的条件。经历拿起、松开与遮挡以后，网络可能学会哪些部分要一起追踪，哪些可以分别更新。对象分组是同一网络可能学成的工作方式，不是预测开始以前就要交付的成品。

预测既不需要完整的输入，也不需要完整的未来。伸手接杯子时，预测可以止于自己的动作，经运动通路直接成为行动；在另一次经历里，也可以有模糊的落势、精确的落点，甚至一段连续画面。这里没有强制的先后顺序，更不需要一个内在的“我”先审查它们。至于一项动作是依赖了对外界的预期，还是只依靠已有经历，要用改变预期的实验来区分，而不是由动作长什么样来判定。

语言起初也在经历里。别人说“当心”是杯子旁边真实发生的另一个事件，不是杯子滑落这件事的缩写。后来一个词能引出另一个词，一句话能引出异议；自己的上半句话又能成为下半句话的条件。作者主张，因果解释、是非与逻辑判断就在这样的语言活动里形成；底层的基本功能并没有从预测变成另一种智能。作者还提出，声音、画面和感觉的内部回输可以延长思维，使人觉得有一个在里面听与说的自己。这是关于人的解释，比“人工网络能把上一步的信号用于下一步”走得更远，也需要另外的证据。

### 18.3 全过程示意

```text
自身和外界在共同变化；当前输入和过往经历进入同一网络
                         ↓
               对后续某些变化形成预期
           ┌─────────────┼─────────────┐
       自己会怎么动      什么会跟着变      下一句话是什么
           ↓                 ↓                 ↓
        动作执行         后来的观测       成为下句话的条件
           ↓                 ↓                 ↓
        实际反馈         印证或修正       解释、异议、判断
           └─────────────┴─────────────┘
                         ↓
                 继续参与联合状态
```

三列是同一过程可涉及的内容，不是三台机器。可以只发生其中一种，也可以相互影响。语言不必夹在感知和每一次行动中间。

### 18.4 最需要保留的四个区别

**联合不等于预测齐全。** 自身动作可以是唯一的预测内容，不是必须从一部隐形的未来影片里剪出来的片段。

**语言来自共同运行。** 不是先有一个设计者把世界编码成符号，而是声音和符号在实践中逐渐获得可以接续其他状态的作用。

**隐式机制与显式描述不是一回事。** 能够说出“因为”或完成一段推理，不等于内部必然另设同名的独立机制；反过来，纯预测的解释也必须面对具体机制证据。

**统一不取消具体实现条件。** 预测世界、语言和自身行动可以属于同一理论，但实际模型仍需要恰当的数据、训练、记忆、反馈和执行通路。

## 附录 A：术语简表

| 术语 | 本文中的用法 |
| --- | --- |
| 状态 | 对某个阶段或范围内实际情况的描述；不把世界观中的“转移”误解成所有事物逐帧跳变 |
| 联合状态 | 自身与外界构成的共同情境，或网络中多种活动构成的共同状态；不要求穷尽全部信息 |
| 分割／分组 | 在联合状态中区分可分别变化的部分，并将应共同追踪的局部归在一起；不等于仅检测边缘或输出掩码 |
| 状态转移 | 一个状态之后出现另一个状态，箭头本身不等于因果证明 |
| 状态转移预测 | 从当前情境与历史形成对某些后续变化的预期；可以粗略、隐式、只涉及自身动作，也可以细致地涉及多种内容 |
| 隐式结构 | 支持可复用预测的内部组织，不预先按人类概念命名 |
| 泛化 | 面对未直接记忆的情境或组合，仍能形成适当预测与行为 |
| 语言形成 | 信号在共同实践中逐渐获得稳定接续作用的过程 |
| 语言自行运行 | 语言产物继续成为预测条件，可以不依赖当前对应场景持续展开 |
| 因果与逻辑 | 本理论试图解释为在语言活动中形成的高级关系与约束 |
| 行动 | 对自身后续行为的预测经运动或控制通路实现；不等于任何想象中的动作都会执行 |
| 局部世界 | 具有局部状态内容与转移描述、能在一定范围内被讨论的系统或区域 |
| 统一隐式空间 | 多种内容可共同影响预测的状态体系，不等于所有模态必须完全同质 |
