# JSTP 和谁比，比较能说明什么？

这里的 JSTP 是一个具体实现，不等于“所有智能都源于预测”的强理论。它先对公开候选 A、B 分别预测联合 RGB 后果，目标在预测之后进入比较；执行器只落实被选未来里的自身运动部分。候选运动不是网络从零生成的。本文同时比较任务结果与**固定动作会让哪些部分一起动**，避免把一个指标替代另一个。

| 路线 | 它在行动时做什么 | JSTP 的着力点；证据等级 |
|---|---|---|
| [OpenVLA](https://arxiv.org/abs/2406.09246) 等动作型 VLA | 从图像和语言生成机器人动作，面向多指令、多任务操作。 | JSTP 给每个候选留下可以事后核对的物理预测，而不仅给动作。本研究不测语言，不部署 OpenVLA；本地完整历史直接策略只是同场动作基线，并非 OpenVLA 的替身成绩。 |
| [π0.7](https://www.pi.website/download/pi07.pdf)、[CoT-VLA](https://research.nvidia.com/labs/cosmos-lab/cot-vla/) | 可利用期望的视觉子目标来控制；“语言＋图像直出动作”不足以概括所有 VLA。 | 目标想要什么和固定动作实际会造成什么可以相反。JSTP 的试题能将两者单独干预；没有证据说这些 VLA 做不到。 |
| [视觉前瞻控制](https://research.google/pubs/deep-visual-foresight-for-planning-robot-motion/)、[DreamerV3](https://doi.org/10.1038/s41586-025-08744-2)、[V-JEPA 2-AC](https://arxiv.org/abs/2506.09985) | 用视频或潜在状态预测支持规划、或从想象轨迹学习行为。 | “用预测指导行动”已有先例，不是 JSTP 的首创。本文的增量是把试探证据、固定动作、物理后果和新目标放到可复算的配对比较中。仅文献对照。 |
| [DINO-WM](https://arxiv.org/abs/2411.04983) | 从预训练视觉 patch 特征学习后果，按目标特征距离规划。 | **有同场实测**：同样的观察、两候选与训练数据，接入官方 ViT-S/14 和原预测器，重新训练任务动力学。熟悉连接/新目标：JSTP 88.7%，适配 50.1%。对微小位移使用了不同的表示、损失和规划距离，不能据此否定原模型或整个潜在世界模型路线。 |
| [DreamZero](https://arxiv.org/abs/2602.15922)、[GR00T 2](https://research.nvidia.com/labs/gear/gr00t-2/)、[Cosmos Policy](https://arxiv.org/abs/2601.16163) | 联合建模动作及未来观察，部分还预测价值并在推理时做规划。 | 不能声称 JSTP 首次联合世界与自身动作；它比这些系统动作自由度更低。本文强项是**逐项干预与诊断**，并非通用机器人技能。仅文献对照。 |
| [AD-WM](https://arxiv.org/abs/2609.30264) | 要求同一状态下不同动作的预测有判别力；预测误差与控制质量不必一致。 | 最接近的思路之一。本文除“同经历，换动作”外，还问“同动作，换回忆证据”，并增加新接线、目标交换和简单规则检验。不是头对头测过 AD-WM。 |
| [OP3](https://arxiv.org/abs/1910.12827)、[主动发现隐藏物理](https://arxiv.org/abs/1611.01843) | 前者用显式实体结构建模视觉世界；后者学习用物理试验暴露隐藏属性。 | 本研究不设对象槽、不训练实例掩码；从有先验的转移网络检验功能性共动。一次试探由实验台规定，不主张率先实现主动实验或已获得持久对象身份。 |

## 哪些优势真的由数据支持？

1. **预测可以被问责。** 前期 V6 同权重、同 100 道题：预测后果结合原动作先验完成 87 道，直接读动作完成 70 道，保留先验但错配候选动作与动力学只完成 69 道。这个有方向的同权重结果支持“这里的预测确实对行动有用”，并非泛指所有环境。主试验中每步可查预测摘要和真实执行结果，允许直接检出失败。
2. **相同材料，学会对比不同后果确实有收益。** 三载荷熟悉连接+新目标，搬运网络的成对目标 vs. 只分别重建四个实做分支：88.7% vs. 49.7%，差 38.9 点，95% 配对区间 [36.8, 41.0]。这是训练目标组合的改善，不是隔离出“理论本身”的纯效应。
3. **能把一次对世界的认识用于不止一个目标，但没有独占这种能力。** 简单双载荷 V7 同一冻结模型 512/512，错换视觉经历 0/512；三载荷熟悉机构双区任务接近直接策略。固定目标不改写物理后果是接口性质；值得测的是它具体预测对了什么。

**最有价值的反例：** 双新时直接策略 68.3%，JSTP 45.8%，显式一位规则 81.25%；给三位和互补机构知识则全对。JSTP 当前并未证明更强的结构迁移。更严谨的论文卖点是“给出能区分任务成功、物理判断、机构外推的实验，并找到了何时有效与何时失效”，不是“击败主流 VLA”。
