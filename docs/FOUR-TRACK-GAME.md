# 潮汐港 · 四轨货运

**[双击出港](../玩四轨调度站.cmd)**。沿用《双舱救援》的甲板、青色泊位和两根绞盘。开场只有一艘小艇和一个发光的泊位；跟手势往下拉，小艇会随手移动。到线松手才交货。点「四舱出港」开正式的游戏关，也可以直接跳过练手。

## 自由港

| 甲板上看到什么 | 可以做什么 |
| --- | --- |
| 金色 A、蓝色 B | **两根都能试。** 握住任何一根向右横拖，看看舱体偏向哪边。拉到槽口松手，绞盘旁会留下这根绳的方向记号。A→B、B→A、反复试同一根都可以；回弹时就能换手。 |
| 轨道上亮着的青框 | 那就是目的地。握一根绞盘往下拉，舱体跟手走。还没松手就能往回拖；也可以中途停下，改用另一根从起点试。不想横试也能直接送。 |
| 小艇、电池、药箱、水罐 | 每单有三处亮泊位，**送到两处就过**。第四舱也会动，但不用管它。到线松手立即揭晓；对号和叉号直接画在对应的舱上。 |
| 去程旗、返航旗 | 接返航单后，船回起点，三个泊位换边，刚才两根绳的试探记录仍在。想再试，照样可以；两单都过才算整趟通过。 |

**看代驾：** 点右上「▶ 看模型玩」。在同一关从去程开始，模型现场选绞盘，不播归档录像。如果你已完整试过绳，代驾沿用你的最后一次试探；如果没有，自由港的演示台会依次试两根，再让模型接手。**试哪根是演示安排，送货选哪根才是模型决定的。** 原冻结模型一次只收一段试探经历，没有用第二个读出来假装模型学会了合并两段记忆。

其余入口在 **☰**：换模型、示范量、种子或港口，也能打开实验仪表看原始相机和模型实际具有的光学预期。F1 是操作图例，F2 是仪表；键盘 A / B 选绞盘，→ / ↓ 拉，← / ↑ 收，空格松手，P 暂停。

## 如果要复现论文那样玩

选 **☰ → 论文赛道**。这里才限制为指定把手试一次；滑块复位后才亮出泊位，去程和返航两个选择都锁定后，才从同一复位点分别执行。选把手时不会提前移动舱体泄露结果。**「论文例题」**对应[论文 §5.1](../studies/joint_primer/paper/联合状态转移预测导论-岳轲.pdf#page=4) 的布局 113670000；「同一港口换订单」能看下一对卡。

自由港与论文赛道使用[同一个四轨装置和相机裁判](../lategoal/rig.py)，但可见信息、反馈时机和试探次数不同，**分开计分**。自由港用同一起点的装置副本响应每次拖动；甲板放大显示实际相机端点间的行程。原始相机只展示起点、真实横试峰值或真实竖拉终点。皮肤、操作提示和裁判结果都不喂给模型。

### 模型看到什么？它操作的是鼠标吗？

**不是纯像素到鼠标。** 人用鼠标拖绞盘；冻结控制器选择 **A 或 B**，模拟器执行那一拉，没有操作 Windows 鼠标或读游戏源代码的控制接口。

模型的公开试探历史是 162 个数：起始相机画面压缩成 72 个亮度格，试拉前后的差值再占 72 个，12 个水平光学位移读数也从图像测得；另有 1 个试拉把手编号、4 个公开的轨道标记和 1 个档位值。目标卡另给，适配器可将它编码成提示词。光学读数不是模拟器的物体真值坐标，仪表和目标也不是让模型从窗口截图做 OCR。各适配自行编码这些公开信息。[观察接口](../lategoal/rig.py) · [模型推理入口](../studies/joint_primer/game_pilots.py)

**测试时**不把隐藏接线、物体真值坐标、正确把手或正式动作后的画面交给控制器；执行后的相机画面用于裁判。**训练时**确实有动作示范标签，这就是 128 / 1,024 / 16,384 三档的含义，不是三种训练轮数。[训练标签](../studies/joint_primer/train.py)

模型仍是原来的[完整 JSTP 与五种外部适配](../studies/fourtrack_foundations/README.md)，支持三档动作标注和三个冻结训练种子。人工不加载模型；完整 JSTP 用 CPU，外部适配需要本机已有的 CUDA 环境和上游权重。游戏不训练、不下载、不写论文记录。
