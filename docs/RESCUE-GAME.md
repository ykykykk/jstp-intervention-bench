# 潮汐港 · 双舱救援

在仓库根目录双击 [玩双舱救援.cmd](../玩双舱救援.cmd)，或在项目虚拟环境中运行 `python -m jstp.rescue_game`。游戏只接收自己窗口内的输入，没有联网或系统鼠标操作。

**第一关：只救乘员，电池要留在原地。** 金色双舷窗是乘员舱，绿色闪电是电池舱。你操纵的是甲板下方的绞盘，不是点一下目的地让舱自己开过去。

1. **试一试接线。** 比如按住 B 向旁边拖一点，看绿电池跟不跟，再松手。这消耗的是本单的一次横向试拉，不是出航选择。可以立刻握 A，不用等 B 的回位动画结束；刚才看到的结果会留在电台里。
2. **亲手送舱。** 如果电池跟着 B 动，这一关就握 A；如果没跟，就握 B。沿选中绞盘的竖轨向青色交付线拖。中途松手会停住，握同一根能继续；如果想换手，先把它退回起点。试过之后两根都能竖拉，都不能再横试一次。
3. **到线再松手。** 拖到交付线时仍可调整，松手才按两个舱的实际位置结算。下一关会换接线，不能背上一关的答案。

- **键盘驾驶：** 例如按 B、按 → 试拉，再直接按 A，按工单对应的 ↑ 或 ↓ 送舱，到线按空格交货。换绞盘不用先按空格；只选中不会移动。Enter 换新关，P 暂停或继续，F1 看玩法。
- **看代驾：** 在尚未操作的工单上点「JSTP 代驾」。它可以直接拉，也可以先试 A 或 B。左边只演真实试拉、复位和交付；右栏的两项是动作前的预测，不是录像。看完一关会自动换新关。
- **同一条线索，另一张工单：** 在「只救乘员」或「双舱转移」里试拉后完成交付，结算时可选「沿用刚才的试探，换张工单」。接线、起始画面和那次试拉都不变，只把电池的目标从走改为留或从留改为走。也可以直接去下一关。

**模型与计分。** 甲板图标是原 V7 模拟器可见位置的放大示意；送达按真实终态相机和目标图逐像素比对。JSTP 读的是原始 RGB 和公开动作，不是甲板图标、文字或隐藏接线。右栏把冻结 V7 的两个候选 RGB 未来图读成「上行 / 下行 / 原位 / 不明」；实际决策沿用早期演示的**独立收益读出**，不是拿这两张显示图直接评分。它从操作结果与耗费学习，不预设哪关要试探。

手动驾驶无需等待模型。旧演示的收益读出没有随 V7 权重存档，因此首次选代驾时，程序会在后台用模拟关卡重新学习它，之后复用本机 `work/rescue-game/` 下的缓存。它不会修改冻结权重。游戏只记本次会话的送达和连胜，不写入论文的考试记录。
