# 晚到的目标 · 研究与复现记录

**问题。** 已经有一条可走的直接动作路，网络还会根据自己对物理后果的预期来行动吗？本研究不预设答案。[论文第 9–12 节](../paper/mechanism_study/manuscript.md)在此前的阴性结果之后追加，没有替换先前成绩。

## 什么算「新的目标」

| 阶段 | 对模型公开 | 尚未公开或从不输入 |
|---|---|---|
| 试探前 | 初始画面、手的停靠侧 | 离合档位、目标、真实接线 |
| 网络选择 A 或 B 横向试探，并回到起点 | 基准画面、试探变化和已发驱动；之后给出离合状态及可逆轨道标记 | 晚到目标、未来相机、正确把手 |
| 预测刚试探的这只手若正式纵拉会怎样 | 网络自己的 64 维隐状态，12 个重叠光学测点的纵向后果可从中读出 | 目标仍未给；不模拟两候选再打分 |
| 通知目标并驱动 | 同一隐状态、保留的完整历史表示、目标卡 | 分割掩码、物体标签、供体该选的把手、外部评分器 |

1、2、3、4 号是任务方给的空间地址，不是网络发明的对象名称。训练卡为所有单轨指令、123 和 234 两个三轨组合上的所有上下指令（共 24 张）；考试卡为 124 和 134（共 16 张），集合交集为空。卡上三个指令中过半达成即成功。相反卡总要求不同把手，不能静止过关。所有考试布局也全新，但物理装置家族不变。

每份模型内部是共享的单一网络，主组、断开后果支路组、仅动作组是**独立训练的对照条件**，并非三个网络联手答题。没有继承旧版权重。传感前端是通用亮度网格和重叠视野的重心变化；控制器没有读真实轨道位移。四输入的可学习目标映射偏好加性组合，这对三组同样有利。探查把手由网络自己给出；“先做一次横拉并复位”是给定时序，不是学会了决定要不要试探。

## 为什么有两种对照

离合能反转两条轨的纵向运动，但不改变先前的横拉。选择具有同一横拉、不同离合的孪生经历作供体。只动自己的后果状态；实际试探、真实离合、目标、历史旁路和权重始终是原来的。四个方向由独立校准布局里的真实光学场及冻结的线性读出确定，不用成功标签。

令物理读出为 `Wz+b`，`P` 是校准光学场的前四个主成分（逐行）。取 `PW` 行空间的正交基 `Q`，只加上 `QQᵀ(z供体−z原)`。这是让所选物理读数与供体对齐所需的最小欧氏改动；隐状态其余部分不动。等幅对照使用相同的四个系数，但沿 `W` 的零空间正交基施加。**它是“对于物理读数无关”，而不是事先保证“对于动作无关”。** 第二个对照则根本不换扰动，只观察同一移植在本不应换手的目标上会不会造成误换。局部移植不保证仍完全落在自然隐状态分布上，因此也记录整段自然供体与等后果供体的结果。

## 判定

| 事前规定的量 | 结果（95% 按布局配对区间） |
|---|---:|
| 同一前缀，两张相反新卡均实际成功 | **99.83%**（99.76–99.89） |
| 应换手题：自然时正确，改物理预期后改为供体正确侧 | **59.93%**（58.83–61.05） |
| 上一项减去等幅零空间对照 | **59.05 个百分点**（57.93–60.22） |
| 上一项的物理换手率减不应换手题的误换率 | **59.40 个百分点**（58.33–60.50） |
| 物理读数由更接近本世界转为更接近供体 | **100%**（在本固定面板上） |
| 联合组相对仅直接动作组的目标对成功率差 | **−0.17 个百分点**（−0.24 至 −0.11） |

三种子在应换手题上的定向变化分别为 53.42%、62.45%、63.93%。所有百分率的原始分母、子条件和完整区间可从[统计代码](../lategoal/analysis.py)和[分种子结果](../evidence/late-goals/analysis/per_seed.csv)重算。两项主判据均通过。这是**后果表征参与动作的证据**，不是证明动作只能由后果产生，也不证明比直接策略更准。晚到目标之外，装置、网络和干预也已改变，不能把本轮与上一轮之差当成单一设计因素的因果效应。

## 三条复现路线

在仓库根目录执行。除重训外均不需要 GPU，也不用任何系统桌面权限；研究不需要外部预训练模型。

**从逐题档案重新计算**（Python 标准库和 NumPy 2.5.5）：

    python scripts/verify_release.py
    python -m lategoal.analysis --release evidence/late-goals --out work/late-recount

**只加载冻结权重，从试探开始实际重做全部正式操作**（需 PyTorch）。不使用原答案控制模型；封卷、真实操作、统计后才与发行记录逐项比较。本次 663,552 个提交、25 份数组归档及汇总无差异。这是同机复演，而非第二次从零训练。

    python scripts/replay_lategoals.py --out work/new-frozen-replay

**从零生成数据并重新训练**（实测 Windows，CPython 3.13.5，RTX 3090，PyTorch 2.15.0+cu132）。程序拒绝覆盖旧目录；如要同时观看该轮训练，第二个终端指向同一轮的 release：

    py -3.13 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r requirements-windows-cu132.txt
    .\.venv\Scripts\python.exe scripts/reproduce_lategoals.py --out work/late-rebuild
    .\.venv\Scripts\python.exe -m lategoal.window --release work/late-rebuild/release

正常重排论文在另一个排版环境安装 `paper/requirements.txt` 后运行 `python paper/mechanism_study/build.py`；脚本读取统计、封存驱动和实测帧指纹生成表格、图 3 和 PDF，不用网络训练环境。
